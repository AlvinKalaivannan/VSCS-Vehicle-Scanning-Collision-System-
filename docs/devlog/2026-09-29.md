  - Maths and stubs in `seg/fusion3d.py`, plus 12 target tests.
  - An exact fixture renderer (masks and depth by ray casting) and the per-component
    IoU metric, both merged to `main`.
- **P2-T5** `seg/cleanup.py`: cluster each label, keep each component's largest
  cluster, reassign strays by neighbour vote, never fill holes.
- **P2-T6** `model/decompose.py`: points → voxel solid → boundary mesh → CoACD
  (MIT, pinned 1.0.14). OBB fallback is available but never auto-selected.
- **P2-T7** `model/joints.py`: URDF joint kinematics, limits, and a check that joints
  match the components.
- **P2-T8** `model/urdf.py`, `model/build.py`, `scripts/export_model.py`: URDF + meshes
  + components.yaml, reload into `veh` at any joint state, and plan footprints for
  `risk/`.

**Evidence:**

- `main`: 657 passed, 1 skipped; ruff clean.
- Fusion (private reference, not committed): IoU 0.993 on clean masks, 0.961 with 20%
  of mask pixels scrambled. Gate 0.70.
- Cleanup: salt noise repaired to IoU ≥ 0.99, with IoU never decreasing.
- Decomposition, L-shape: a single hull is +16.7%; CoACD is +0.4% (6 parts); OBB is
  +32.6%, correctly failing the gate.
- Export round trip: rear-right corner footprint to pole = 0.500 m (§5 known answer).
  The right mirror folded 90° ends at y = -1.10 exactly.

**What failed / surprised me:**

- Fusion ground truth first penalised points on hidden internal faces. A real scan has
  no such points; the tests now judge only visible surface points.
- Voxel filling is all-or-nothing, and it failed for two separate reasons:
  - Poisson gaps when spacing > ~0.3 voxel. This is now a config threshold with a
    warning.
  - Faces lying exactly on voxel boundaries. Fixed with a half-voxel grid offset.
- The voxel solid runs ~1 cm large per side at 2 cm voxels (+23–25% volume on small
  fixture parts). The P2-T6 gate cannot see this, because it compares parts with the
  same solid. Documented and tested. `voxel_m: 0.01` halves it at ~8× compute: the
  developer's call.
- I wrongly stamped the licence checks 2026-09-30. Corrected.

## Session (cont.): P2-T2 masks stage; Wave 1 complete

**What I did:**

- `seg/masks2d.py`, `scripts/seg.py`, `notebooks/colab/20_seg.ipynb`: detect on keyframes,
  track with SAM 2, compose each frame by highest logit, save per-frame label PNGs, 20
  seeded check overlays, and a list of components never detected.
- The models (Grounding DINO tiny, SAM 2.1 small; Apache-2.0) are injected, so the logic
  is tested here with fakes. The real adapters run only on Colab.

**What failed / surprised me:**

- The first design held every frame's logits for every component: ~34 GB for a
  300-frame 1080p scan. Rebuilt to stream one frame at a time.
- Repeat visits (forward and reverse tracking passes) are merged by keeping only
  (winner, logit) per pixel. A test proves this matches keeping every logit.
- SAM 2 propagation only runs forward from the first prompt. Now forward from the
  earliest prompt and reverse from the latest, so each component is tracked across the
  whole scan.
- Frames and tracking state are offloaded to CPU RAM for the 16 GB T4.

**Evidence:** `main` 668 passed, 1 skipped. On the fixture, the pipeline reproduces the
exact masks, drops a low-score decoy box, and logs `underbody` as never detected from a
standing-height scan.

**Unverified until the first Colab run:** the real adapters, and the exact
`transformers` and `sam2` versions. Record the working combination in an ADR (R-12).
